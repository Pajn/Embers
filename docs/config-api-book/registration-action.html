fn resize_left(_: ActionApi, cells: int) -> Action
Move the focused pane's border `cells` cells left (tmux `resize-pane -L`).

The nearest split with panes side by side is resized: the divider to the right of the pane moves left, shrinking the pane, or, when the pane is the split’s rightmost child, the divider to its left moves left, growing it. Panes keep at least one column of content, and the action does nothing when there is no such split or the divider cannot move. While a pane is zoomed only splits inside the zoomed view can be resized.

fn set_synchronize_panes 

fn set_synchronize_panes(_: ActionApi, enabled: bool) -> Action
Turn tmux-style `synchronize-panes` on or off for the active window.

The setting belongs to the window (a root tab) and is shared by every client. While it is on, keys, pastes and send_keys_current/send_bytes_current input aimed at the focused pane go to every pane the window shows, each encoded for that pane. Panes in hidden nested tabs or hidden by zoom, panes in other windows, and popups are left out, and input typed into a focused popup is never copied. Mouse and focus events, input sent to a specific buffer id, and embers send-keys are not synchronized. Tab bars can show the state through TabInfo.synchronize_panes().
